## 🛠️ Quy trình dịch thuật

1. Đọc file gốc từ repository [vuejs/docs](https://github.com/vuejs/docs)
2. Dịch nội dung sang tiếng Việt, giữ nguyên cấu trúc Markdown
3. Giữ nguyên code snippets và technical terms
4. Đồng bộ terminology với các file đã dịch
5. Kiểm tra định dạng và link
6. Test local với `pnpm run dev`
7. Commit theo quy trình git
